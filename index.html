post_add Hướng dẫn thêm môn học mới

Hệ thống hỗ trợ tạo không giới hạn các môn học khác (Hóa học, Toán, Lý, Pháp luật, Triết học...). Để thêm môn mới, bạn chỉ cần thực hiện 3 bước:

1
Mở file data.js

Mở file data.js trong thư mục dự án trên máy tính.

2
Dán đoạn code môn mới vào danh sách window.SUBJECTS_DATA

Sao chép mẫu bên dưới, chỉnh sửa tên môn, các chương và câu hỏi theo ý bạn:

{
  id: "hoa_dc",
  name: "Hóa học đại cương",
  code: "HDC",
  desc: "Đề cương ôn tập trắc nghiệm Hóa học đại cương",
  icon: "science",
  color: "#4285f4",
  chapters: [
    {
      id: "ch1",
      title: "Chương 1: Cấu tạo nguyên tử & Bảng tuần hoàn",
      short: "Cấu tạo nguyên tử",
      questions: [
        {
          n: 1,
          q: "Hạt mang điện tích âm trong nguyên tử là:",
          o: ["Proton", "Neutron", "Electron", "Positron"],
          a: 2,
          exp: "Electron mang điện tích âm (-1), proton mang điện dương (+1), neutron không mang điện."
        }
      ]
    }
  ]
}
3
Lưu file và nhấp đúp day-len-github.bat

Render sẽ tự động cập nhật môn học mới lên web của bạn chỉ sau 1 phút!
